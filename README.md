## 🚀 Installation & Setup

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/your-repo/zebra-puzzle-pro.git
    cd zebra-puzzle-pro
    ```

2.  **Open in Xcode**
    - Drag the `src` folder into your Xcode project.
    - Ensure `Models.swift` and other Core files are added to your target.

3.  **Run the App**
    - Select the `PuzzleView` as your root view in `ContentView.swift`.

## 🎨 Adding New Themes

The Theme Engine is data-driven. To add a new theme (e.g., "Japanese Anime"):

1.  Create `src/Data/Themes/ja_anime.json`.
2.  Follow the schema defined in `ThemeDefinition` (see `src/Core/ThemeEngine.swift`).
3.  Define Categories (Characters, Powers, Weapons).
4.  Define Clue Templates for logic rules (`isSame`, `nextTo`, etc.).
5.  Load it via `ThemeEngine.shared.loadTheme(...)`.

## 📱 iOS Integration Guide

The `Core` module is designed to be a standalone Swift Package.

1.  **Move `src/Core`** to a new Swift Package target.
2.  **Import Core** in your SwiftUI views.
3.  **UI Customization:** `PuzzleView` is a reference implementation. You can build completely custom UIs (e.g., drag-and-drop) using the `ZebraPuzzle` and `PuzzleRule` models.
